## ⚡ Streaming Optimization Guide

### Step 1 — Use Ethernet

For the best chance of a stable connection, connect the PlayStation 5 directly to the router using an Ethernet cable.

A wired network reduces exposure to common Wi-Fi interference.

### Step 2 — Review Bandwidth

Sony specifies a minimum connection speed of 5 Mbps for Remote Play and recommends at least 15 Mbps upload and download for best performance.

Actual connection quality also depends on latency, packet loss and network stability.

### Step 3 — Reduce Congestion

Limit unnecessary bandwidth usage during remote sessions.

Examples:

- Large game downloads
- Cloud backup uploads
- High-bandwidth streaming
- Background software updates

### Step 4 — Configure Video Quality

Review the available video quality options in the official Remote Play client.

Choose a configuration appropriate for the network.

### Step 5 — Troubleshoot Input Delay

1. Test the connection on the local network.
2. Connect the PC using Ethernet when possible.
3. Check controller connectivity.
4. Reduce unnecessary display processing.
5. Compare local PS5 gameplay with Remote Play.
